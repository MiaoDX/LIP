# Human Docs

This folder holds human-facing detail that would make the root docs too large.

Current root orientation:

- `README.md`: project purpose, content map, publishing conventions, and
  recommended reading.
- `ARCHITECTURE.md`: publishing architecture, source owners, build flow, and
  proof boundaries.
- `STATUS.md`: current state, supported commands, maintenance focus, and known
  blockers.
- `ROADMAP.md`: content roadmap and backlog.

Agent-only procedures stay in `docs/agents/`. Planning and execution evidence
stay in `docs/plans/` and `docs/status/` unless explicitly promoted into this
human-facing surface.
