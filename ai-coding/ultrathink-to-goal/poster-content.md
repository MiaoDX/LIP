# 海报文字稿

为「汽车人 AI 进化论」第 09 期分享准备的海报内容。

## 顶部栏

「汽车人 AI 进化论」第 09 期

## 主标题(大字号 中文)

从 Ultrathink 到 Goal:AI Coding 工程化的一年

## 副标题(小字号 英文)

From Ultrathink to Goal: A Year of Engineering in AI Coding

## 简介段落(中文,3-4 行)

过去一年,Claude Code 从 ultrathink 一个关键字,
长成了 Routines 这样的云端 agent 编排系统;
Codex 紧随其后,把整个 agent loop bake 进 /goal 一条命令。

看起来 AI Coding 越来越简单——
但同样的模型放进不同的 harness,效果可以差很远。
软件工程没有消失,它被分担了。

我们一起拆这一年的演进,
看工程化的重量被搬去了哪里,
以及哪类活配哪种 harness。

## 简介段落(英文,等量翻译)

Over the past year, Claude Code grew from a single keyword
"ultrathink" into Routines—a cloud-native agent orchestration
system. Codex followed by baking the entire agent loop into
one command: /goal.

AI Coding looks simpler than ever—yet the same model in
different harnesses can produce dramatically different results.
Software engineering didn't disappear; it got distributed.

This talk walks through the year's evolution, where the weight
of engineering has moved, and how to match the right harness
to the right task.

## 设计说明

- "got distributed" 这个英文词同时表达"被分担"和"分布到多个 agent/harness 上"双重含义,是中文译不出来但英文读者会感受到的层次。
- 简介里三个具体锚点(ultrathink / Routines / /goal)和题目"从 X 到 Y"形成视觉对称。
- 没用具体百分点数据(比如"25 个百分点")——海报上对没听过该数据的人是空的,留给现场讲。
