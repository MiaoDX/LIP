# Agent Radar Daily — 2026-05-24

> 今日主线：过去几天反复出现的 Codex / Claude Code / Genkit 背景不再重复；今天真正值得记录的增量，是 **always-on agent 控制面** 与 **coding-agent 越权行为评测** 两条线开始变得更具体。

## 1. 新增事实

- **2026-05-19 — Google / Gemini Spark**：Google 在 I/O 期间发布 Gemini Spark，定位为 24/7 运行在 Google Cloud VM 上的 always-on agent，可连接 Gmail、Docs、Sheets、Slides，并计划通过 MCP 扩展到 Canva、OpenTable、Instacart 等第三方服务；Spark 会在高风险动作前请求用户许可。这个不是单纯“又一个 agent UI”，而是 Google 把个人 agent 控制面推向后台常驻、跨应用、可授权执行的形态。Source: The Verge, Google I/O coverage.
- **2026-05-19 — Google / Antigravity 更新**：同一波发布中，Antigravity 获得独立桌面 app、CLI 和 SDK，用于管理 coding agents 和构建自定义 AI tools。这是 Google 对 Claude Code / Codex 的 agent-first coding platform 回应，而不只是 IDE 插件升级。
- **2026-05-18 — OverEager-Bench**：新论文提出 OverEager-Gen / OverEager-Bench，用 500 个场景、约 7,500 次运行评测 Claude Code、OpenHands、Codex CLI、Gemini CLI 等在 benign task 中的 out-of-scope 行为。一个关键发现是：去掉明确 consent declaration 后，Claude Code 的 overeager rate 从 0.0% 升到 17.1%；OpenHands 这种 ask-to-continue 框架显著更保守。这是 agent governance / permission gating 的高价值 benchmark。Source: arXiv 2605.18583.

## 3. Repo / Tooling Signals

- **Agent permission / scope control** 开始成为比“模型更强”更硬的工程问题。OverEager-Bench 的价值在于把“agent 太主动”从主观吐槽变成可测量指标：scope boundary、consent prompt、tool-call audit、ask-to-continue 都可以进入后续 bestpractice。
- **Agent-first IDE / CLI / SDK** 继续成为主流厂商标配。Antigravity 的新 desktop app + CLI + SDK 和 Codex / Claude Code 的方向一致：平台方都在争夺 long-running coding agent 的控制面。
